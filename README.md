# Sistema de Pedidos em Python

Sistema de pedidos desenvolvido em Python para simular o gerenciamento de uma lanchonete.

## Funcionalidades

- Cadastro de clientes com validação e idade mínima de 18 anos
- Cardápio organizado por categorias
- Seleção de múltiplos produtos e cálculo automático dos subtotais
- Desconto automático da loja
- Desconto adicional para pagamento via PIX
- Pagamento via PIX, cartão ou dinheiro
- Cálculo de troco
- Geração de número e data do pedido
- Salvamento dos pedidos em arquivo JSON
- Listagem e busca de pedidos
- Cancelamento de pedidos com registro de data e status

## Tecnologias

- Python
- JSON
